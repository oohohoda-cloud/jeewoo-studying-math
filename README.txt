지우의 수학 연습장 - 계산 화면 기능 시제품 v0.1

[사용 방법]
1. index.html 파일을 Chrome 또는 Samsung Internet 브라우저로 엽니다.
2. 화면 중앙에 나온 세로셈 문제를 풉니다.
3. 일의 자리 답안 칸이 기본으로 선택됩니다. 다른 자리 숫자를 쓰려면 그 칸을 직접 누릅니다.
4. 숫자 입력 후에는 자동으로 다른 칸으로 이동하지 않습니다.
5. 받아내림은 윗줄 십의 자리 숫자를 눌러 감소한 숫자를 입력하면 일의 자리 위에 10이 자동 표시됩니다.
6. 받아올림은 윗줄 십의 자리 숫자를 눌러 1을 입력합니다.
7. 덧셈의 백의 자리 올림은 윗줄 십의 자리 왼쪽의 빈 영역을 눌러 1을 입력합니다.
8. 메모를 전혀 사용하지 않고 답안만 입력해도 됩니다.
9. 최종 답안 제출을 누르면 정답 여부를 판정합니다. 정답이면 다음 예시로 넘어갑니다.
10. 다른 문제를 바로 체험하려면 아래쪽 '체험용 예시 바꾸기'를 누르세요.

[6개 확인용 계산 예시]
52-27 = 25: 받아내림
27+15 = 42: 십의 자리 받아올림
67+58 = 125: 받아올림 두 번
40-17 = 23: 0을 포함한 받아내림
23+14 = 37: 받아올림 없음
63+42 = 105: 백의 자리 받아올림

[이번 버전 개발 범위]
완료: 세로셈 조작 화면, 받음 메모, 자리별 답안, 오답 효과, 제출 채점, 일시정지, 6개 예시
제외: 기록 도전 랜덤 생성, 왕관 보상, 일자별 성적, 기록 저장, PWA 설치

이 버전은 계산 조작 UX를 검증하기 위한 1차 시제품입니다.
최종 게임 앱으로 배포하거나 공식 기록을 측정하는 데 사용하지 마세요.
