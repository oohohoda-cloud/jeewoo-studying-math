지우의 수학 연습장 v1.0 (첫 통합 개발본)

배포 방법
1. ZIP 압축을 풉니다.
2. jiwoo-math-v1 폴더 안의 index.html, app.js, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png 파일을 모두 GitHub 저장소 최상위에 업로드합니다.
3. GitHub 저장소 Settings > Pages > Build and deployment > Deploy from a branch > main / (root) > Save.
4. 발급된 HTTPS 주소를 모바일 브라우저로 열고 홈 화면에 앱 설치합니다.
5. 기존 계산 시제품 저장소와 구분해서 배포하거나 기존 파일을 전부 교체합니다.

포함 기능: 연습 유형/문제 수 선택, 10문제 기록 도전, 세로셈 메모, 정답 제출, 오답 페널티, 왕관 기록, 일시정지/이어하기, 오프라인 캐시.
주의: 기록은 브라우저 저장소에만 저장되므로 앱 데이터 삭제/기기 변경 시 사라질 수 있습니다.
주의: v1.0은 첫 통합 개발본이며 실제 Android 기기에서 전체 회차 완주, 왕관 갱신, 오프라인 재실행을 검증해야 합니다.
